# Удаление списка уронов из battle_damage_tooltip_gm.user.js

## Запрос пользователя
В боевом чате висит кнопка «Список🔽» — непонятно зачем. Просьба: убрать этот функционал.
Выбранный объём: вырезать целиком (кнопка + select цели + «Сменить сторону» + refresh() + мёртвый код).

## Что это было
`refresh()` строил панель в чате: выбор защищающегося существа (select), таблица всех
атакующих с мин/макс уроном, убитыми, коэф. урона, адским пламенем, штормом и магией;
кнопка «Сменить сторону» переключала сторону, ❌ сворачивала панель.
Дублирует hover-тултип и индивидуальный расчёт по двум кликам, которые остаются.

## Что остаётся
- hover-тултип урона
- индивидуальный расчёт (клик по атакующему → клик по цели), `individual_calc`
- ❌ (`#collapse`) — теперь закрывает только индивидуальный расчёт
- настройки расстояния, скорости анимации, маг. урона
